## Running the app locally

```bash
npm install
npm run dev
```

## Building for production

```bash
npm run build
npm run preview
```

## Deploying

Any static hosting service can be used. After running `npm run build`, upload the
contents of the `dist` folder. Services such as Netlify, Vercel or GitHub Pages
provide free temporary hosting suitable for quick demos.
